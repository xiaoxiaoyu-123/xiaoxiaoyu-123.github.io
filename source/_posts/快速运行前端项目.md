# 🚀 快速运行前端项目

## 🔧 环境配置

### 1. 安装 Node.js
- 访问 [Node.js 官网](https://nodejs.org/zh-cn/download) 下载 
- 安装完成后验证：

  ```bash
  node -v
  ```

### 2. 安装 pnpm
- 使用 npm 全局安装 pnpm：

  ```bash
  npm install -g pnpm
  ```

### 3. 安装 Trae IDE
- 访问 [Trae 官网](https://www.trae.cn/) 下载并安装

## 📦 安装依赖

1. 进入项目目录：

  ```bash
  cd path/to/your/project
  ```

2. 使用 pnpm 安装依赖：

  ```bash
  pnpm install
  ```

## ▶️ 运行项目

启动开发服务器：

```bash
pnpm dev
```

- 服务器启动后，在浏览器中访问终端显示的地址（通常是 `http://localhost:5173`）
- 修改代码时，页面会自动刷新

## 💡 实用提示
- **依赖问题**：删除 `node_modules` 和 `pnpm-lock.yaml` 后重新运行 `pnpm install`
- **端口占用**：在 `package.json` 中修改端口配置
- **构建项目**：使用 `pnpm build` 命令构建生产版本

## 🎯 总结

核心步骤：
1. 安装 Node.js
2. 安装 pnpm
3. 安装项目依赖：`pnpm install`
4. 运行项目：`pnpm dev`

开始你的前端开发之旅！🎉

## 📖 第一章：初识CSS

### 什么是CSS？主要作用是做啥的？
CSS（Cascading Style Sheets，层叠样式表）是用于控制网页视觉表现的语言。如果说HTML是网页的骨架，那么CSS就是网页的皮肤和衣服。
### CSS根据书写位置，可以分为几类？
根据书写位置，可以分为以下三类：
- 行内样式表-写到标签内部可以控制，当前标签的样式。
- 内部样式表-写到head标签中，可以控制当前页面的样式。
- 外部样式表-独新建一个CSS文件，控制整个网站的样式。
相关代码：
```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>内联和内部样式表</title>
    <link rel="stylesheet" href="./css/外部样式表测试.css">
    <style>
        /* 内部样式表：在HTML文档的<head>标签中使用<style>标签定义样式 */
        div {
            color: blue;
            font-size: 16px;
        }
    </style>
</head>

<body>
    <h2>内联样式表</h2>
    <!-- 内联样式表：直接在HTML标签中使用style属性定义样式 -->
    <p style="color: red; font-size: 14px;">这是一个红色的段落。</p>
    <!-- 内部样式表：在HTML文档的<head>标签中使用<style>标签定义样式，优先级次于内联样式表。 -->
    <div>这是一个蓝色的段落。</div>
    <!-- 外部样式表：将样式定义在外部的CSS文件中，通过<link>标签引入，优先级最低。 -->
    <span>这是一个绿色的段落。</span>

    <!-- 总结：
    内联样式表：直接在HTML标签中使用style属性定义样式，优先级最高。
    内部样式表：在HTML文档的<head>标签中使用<style>标签定义样式，优先级次于内联样式表。
    外部样式表：将样式定义在外部的CSS文件中，通过<link>标签引入，优先级最低。
    -->
</body>

</html>
```



## 🎯 第二章：基础选择器详解 - CSS的"定位器"

### 基础选择器是什么？
基础选择器指的是有单个选择器组成，常见的有：
- 1.类型（标签）选择器，用于设置标签的通用样式（比如重置body的默认边距，统一所有<p>的行高）
- 2.类选择器，日常样式的主力军（90%的样式都用它，可重复使用，最灵活）
- 3.id选择器，用于唯一的页面结构元素（比如页面头部、导航栏、底部这些唯一的大块区域）
- 4.通配符选择器，全局样式初始化（最常用于清除所有元素的默认边距）

### 标签（类型）选择器
类型选择器选择某个类型的元素，也称为标签选择器
使用语法如下：
```
div {
            color: pink;
            font-size: 18px;
        }
```
含义：选择所有的div标签修改样式：文本颜色改成粉色，字体大小为18px

### 类选择器
类选择器选择1个或者多个元素，实现差异化选择
使用语法如下：
```
css:
<style>
    .pink {
        color: pink;
        font-size: 20px;
    }
</style>

html:
<div class="pink"> Hello World </div>
```
含义：选择类名为pink的标签修改样式，文本颜色改成粉色，字体大小为20px
注意：
- 1.类名自定义，不能是中文，纯数字
- 2.多个英文单词组成尽量使用-链接
- 3.类名要有意义，尽量见名知义
- 4.class属性可以有多类名中间用空格隔开

### id选择器
选择HTML中具有特定id属性的唯一元素，
使用语法如下：
```
css:
<style>
    #pink {
        color: pink;
        font-size: 20px;
    }
</style>

html:
<div id="pink"> Hello World </div>
```
含义：选择id名为pink的标签修改样式，文本颜色改成粉色，字体大小为20px。
注意：
- 1.选择特定id属性的唯一元素
- 2.同一页面中，id值必须唯一
- 3.后期主要是配合JavaScript添加交互效果

### 通配符选择器
通配符选择器可以选择HTML中所有的标签，进行样式修改。
使用语法如下：
```html
* {
    margin: 0; /* 去除所有元素的外边距*/
    padding: 0; /*清除所有元素的内边距 */
    box-sizing: border-box:/*统一盒模型 */

  }
```
特殊情况下通过通配符清除所有元素的默认边距和填充，统一不同浏览器的默认样式。

### 四大基础选择器对比
| 选择器类型   | 语法        | 作用             | 使用频率 | 特点               |
| ------------ | ----------- | ---------------- | -------- | ------------------ |
| 标签选择器   | 元素名{...} | 选择所有同类标签 | ⭐⭐⭐      | 全局设置、重置样式 |
| 类选择器     | .类名{...}  | 选择指定类元素   | ⭐⭐⭐⭐⭐    | 最灵活、可复用     |
| id签选择器   | #id名{...}  | 选择唯一id元素   | ⭐⭐       | 唯一性、优先级高   |
| 通配符选择器 | *{...}      | 选择所有元素     | ⭐        | 全局重置、性能注意 |



## 🔗 第三章：关系选择器 - 精准定位元素

### 关系选择器是什么？
关系选择器是通过位置关系来选择目标元素（标签），可以更精准选择某些元素。常见的有：
- 1.后代选择器，
- 2.子代选择器
- 3.邻接兄弟选择器
- 4.通用兄弟选择器

### 后代选择器
选择某个元素的后代元素（不限层级，包括子元素、孙元素等） 
使用语法如下：
```html
css:
div p {
    color: pink;
}
html:
<div> 
    <p>我是粉色的文字</p>
</div>
<p>我是文字</p>
```
说明：选择div标签里面的p元素，中间空格隔开。
父级div作用是限定，子元素p修改样式。
父级和子级都可以是任意选择器

### 子代选择器
选择某个元素的直接子元素（仅限一层）
使用语法如下：
```html
CSS:
div>span {
    color: pink;
}

html:
<div> 
    <span>我是儿子（粉色的）</span>
    <p>
        <p>我是孙子</p>
    </p>
</div>
```
说明：选择div标签里面的第一层span元素，中间>隔开，理解为亲儿子。

### 兄弟选择器

- 邻接兄弟选择器，选中跟在h2后面的第一个p元素，使用语法：h2+p。
- 通用兄弟选择器：选中紧跟在h2后面的所有p元素，使用语法：h2~p。

### 关系选择器总结
| 选择器类型     | 语法 | 选择范围             | 使用频率 | 实例                   |
| -------------- | ---- | -------------------- | -------- | ---------------------- |
| 后代选择器     | A B  | 所有后代             | ⭐⭐⭐⭐⭐    | ul li {color: pink}    |
| 子代选择器     | A>B  | 直接子元素（仅一层） | ⭐⭐       | div>span {color: pink} |
| 邻接兄弟选择器 | A+B  | 紧邻的下一个同级元素 | ⭐        | h2+p                   |
| 通用兄弟选择器 | A~B  | A之后的所有同级元素  | ⭐        | h2~p                   |



## 🎨 第四章：字体样式 - 文字的"美容师"

### 字体颜色 color
- 1.关键字，例如red、grenn、blue等
- 2.十六进制，十六进制颜色值由6个十六进制数字组成，每个数字的范围是0-9、a-f
- 3.rgb/rgba格式，rgba由红色、绿色、蓝色三个通道组成，每个通道的取值范围是0-255，透明度通道的取值范围是0-1
- 4.hsl/hsla格式，hsl颜色值由色相、饱和度和亮度组成，每个值的范围是0-360、0-100%、0-100%
📚四种颜色表示方式对比
| 表示方式 | 语法示例                       | 使用场景                     | 使用频率 | 优点                           |
| -------- | ------------------------------ | ---------------------------- | -------- | ------------------------------ |
| 关键字   | color: pink;                   | 学习使用                     | ⭐⭐       | 简单直观，易记忆               |
| 十六进制 | color: #ff0000;                | 开发最常用                   | ⭐⭐⭐⭐⭐    | 精确控制，兼容性好             |
| rgb/rgba | color: rgba(49, 233, 64, 0.1); | 动态颜色、透明度             | ⭐⭐       | 直观，可计算                   |
| hsl/hsla | color: hsl(0, 100%, 50%);      | 动态主题、颜色计算、设计系统 | ⭐⭐⭐      | 最符合直觉，易于调整，语义化强 |

### 字体族font-family
字体族font-family，给定一个有先后顺序的，由字体名或者字体族名组成的列表来为选定的元素设置字体。
属性值用逗号隔开，浏览器会选择列表中第一个该计算机上安装有的字体。
使用示例：
```css
body {
    font-family:Arial,Helvetica,sans-serif;
}
```

### 字体大小font-size
font-size可设置字体大小，像素px，CSS像素（CSS Pixel）是CSS中用于定义长度、尺寸的单位（简写为px）。
不同浏览器默认字体大小不一样，谷歌默认16px，建议给body标签统一指定大小，做到浏览器统一。
使用示例：
```css
body{
    font-size: 14px;
}
```

### 字体粗体font-weight
font-weight设置文字的粗体大小。
使用场景：
- 1.很多标题是不要加粗的，此时CSS取消加粗。
- 2.部分大批量文字可以利用CSS加粗。
属性值：
- 1.normal：正常粗细
- 2.bold:加粗
数字属性值：（常用）
- 1.400：正常粗细
- 2.700：加粗
- 3.说明：取值范围100~900之间，常用就是400和700.

### 字体风格font-style
font-style用来打开和关闭文本italic（斜体）。
属性值：
- normal：将文本设置为普通字体（将存在的斜体关闭）
- italic：如果当前字体的倾斜版本可用，那么文本设置为倾斜版本
使用示例：
```css
/* 设置斜体样式 */
p {
    font-style: italic;
}
/* 让em斜体取消 */
body {
    font-style: normal;
}
```

### 字体装饰text-decoration
设置或取消字体上的文本装饰。
使用场景：
- 1.最常见设置链接设置下划线，比如取消下划线。
- 2.特殊情况添加删除线。
属性值：
- 1.none:取消文本装饰
- 2.underline:下划线
- 3.overline:上划线
- 4.line-through:穿过文本的线（删除线）

### 字体样式总结
| 属性            | 描述               | 常见取值                                     | 示例                        |
| --------------- | ------------------ | -------------------------------------------- | --------------------------- |
| color           | 设置文本内容颜色   | 颜色名称（red、blue），十六进制，rgba,hsla   | color:red； color:#3366cc； |
| font-family     | 设置文本的字体系列 | 无衬线字体                                   | font-family:Arial,Helvetica |
| font-size       | 设置文本的大小     | px,rem,em,百分比                             | font-size:14px;             |
| font-weight     | 设置文本的粗细     | 数值（100~900），关键字（normal，bold）      | font-weight:400；           |
| font-style      | 设置文本的样式     | normal（正常），italic(斜体)                 | font-style:normal           |
| text-decoration | 设置文本的装饰效果 | none(无装饰)，line-through(删除线),underline | text-decoration:none        |



## ✍️ 第五章：文本布局 - 排版的"建筑师"

### 文本对齐text-align
text-align控制文本在它所在的块级盒子内如何水平对齐
使用场景：
- 1.文本/图片在盒子水平对齐。
- 2.文章文字两端对齐。
属性值：
- 1.left；文本左对齐（默认）
- 2.right：文本右对齐
- 3.center：文本水平居中对齐
- 4.justify：自动改变字间距，两端对齐
使用示例：
```css
div {
    text-align: center;
}
```

### 首行缩进text-indent
设置块级元素中文本前面空格（缩进）的长度
使用场景：
- 1.段落首行缩进2个字的效果。
- 2.logo隐藏文字效果。
属性值：
- 数字，常见单位是em,相对单位，本元素的文字大小1em等于当前元素的字体大小，如果当前元素没有大小，则按照父元素文字大小
使用示例：
```css
p {
    text-indent: 2em;
}
```

### 字间距letter-spacing
letter-spacing用于设置文本字符的间距
使用场景：
- 调整字与字之间的距离，用户体验更好
属性值：
- 数字px
使用示例：
```css
p {
    letter-spacing: 2px;
}
```

### 行高line-height
line-height设置文本每行之间的高
使用场景：
- 1.设置多行文本之间的上下间距。
- 2.让单行文本垂直居中
- 3.行高等于盒子高度，则单行文本垂直居中。
属性值：
- 1.数字px
- 2.数字不带单位（当前字体大小的倍数）
使用示例：
```css
p {
    /* line-height:25px; */
    line-height: 1.5;
} 
```

### 文本布局总结
| 属性名         | 作用                     | 核心取值             | 注意事项                | 示例                     |
| -------------- | ------------------------ | -------------------- | ----------------------- | ------------------------ |
| text-align     | 设置文本的水平对齐方式   | left、right、center  | 仅对块级元素生效        | p {text-align:center;}   |
| text-indent    | 设置首行文本的缩进量     | 长度值（如20px,2em） | 仅对块级元素生效        | p {text-indent: 2em;}    |
| letter-spacing | 设置文本中字符之间的差距 | 数值(px)             | 负值可使字符重叠        | h1 {letter-spacing:2px;} |
| line-height    | 设置文本行与行垂直间距   | 像素或者倍数         | 行高=盒高，文字垂直居中 | p {line-height: 1.5；}   |



## 🔍第六章：分组选择器和伪类选择器- CSS的"智能定位"

### 分组选择器
是将不同的选择器组合在一起，使用逗号分割，也称为并集选择器。
使用场景：
- 1.多个元素具备相同样式。
使用示例：
```css
div,p {
    color: pink;
}
```

### 伪类选择器
选择元素的特定状态或结构位置，符号是冒号(:)
伪类选择器分为三种：
- 1.状态伪类，根据用户交互或状态变化选择。比如：鼠标经过链接、表单获得焦点等
- 2.结构伪类，根据元素的位置选择。比如：选择第5个第10个元素、选择前3个元素等
- 3.表单伪类，针对表单元素的状态。比如：表单禁用、选中复选框等

#### 状态伪类选择器
状态伪类选择器有：
- 1.链接伪类选择器
- 2.用户行为伪类选择器

##### 链接伪类选择器
链接伪类主要用于根据链接的不同状态（如未访问、悬停、点击deng）为其添加样式，从而提升用户体验和界面交互性。
实际开发，一般这样写：
```css
/* 淘宝 */
a {
    text-decoration: none;
}
a:hover {
    text-decoration: underline;
}

/* 京东 */
a {
    color: #666;
    text-decoration: none;
}
a:hover {
    color: #ff0f23;
}

/* 小米 */
a {
    color: #757575;
    
}
a,a:hover {
    text-decoration: none;
}
a:hover {
    color: #ff6700;
}
```

##### 用户行为伪类选择器
用户以某种方式和文档交互的时候应用，这些用户行为伪类，有时叫做动态伪类。
使用场景：
- 1.鼠标经过元素的时候，修改样式。
- 2.表单获得焦点的时候。
属性：
| 动态伪类 | 作用                 |
| -------- | -------------------- |
| ：hover  | 鼠标经过元素         |
| ：focus  | 获得焦点的元素(表单) |
使用示例：
```css
 /* 获得焦点时 */
        .search {
            width: 100px;
            height: 20px;
            transition-duration: .5s;
        }

        .search:focus {
            width: 200px;
            background-color: skyblue;
        }
        /* html */
<input type="text" class="search">
```


#### 结构伪类选择器
结构伪类选择器，根据元素的位置选择目标元素。
使用场景：
- 1.选择第1个或者最后一个或者第n个元素。
属性：
| 结构伪类     | 作用                         |
| ------------ | ---------------------------- |
| ：fist-child | 一组兄弟元素中的第一个元素   |
| ：last-child | 一组兄弟元素中的最后一个元素 |
| ：nth-child  | 一组兄弟元素列表中第n个元素  |
使用示例：
```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>结构伪类选择器</title>
    <style>
        ul li:first-child {
            color: pink;
            /* 选择ul下的第一个li元素的字体颜色为粉色 */
        }

        ul li:last-child {
            color: skyblue;
            /* 选择ul下的最后一个li元素的字体颜色为天蓝色 */
        }

        ul li:nth-child(3n) {
            color: green;
            /* 选择ul下的第3、6、9...个li元素的字体颜色为绿色 */
        }

        ul li:nth-child(5) {
            color: #d5ec24;
            /* 选择ul下的第5个li元素的字体颜色为黄色 */
        }
    </style>
</head>

<body>
    <ul>
        <li>列表项1</li>
        <li>列表项2</li>
        <li>列表项3</li>
        <li>列表项4</li>
        <li>列表项5</li>
        <li>列表项6</li>
        <li>列表项7</li>
        <li>列表项8</li>
        <li>列表项9</li>
        <li>列表项10</li>
    </ul>
</body>

</html>
```

#### 表单伪类选择器
表单伪类选择器，针对表单元素的状态。
使用场景：
- 1.表单按钮禁用的时候，调整颜色。
- 2.复选框选中修改样式。
属性：
| 表单伪类   | 作用                   |
| ---------- | ---------------------- |
| ：disabled | 表单禁用               |
| ：checked  | 选中状态，单选复选按钮 |
使用示例：
```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>表单伪类选择器</title>
    <style>
        /* 按钮的背景颜色 #ff6900 */
        button {
            width: 150px;
            height: 40px;
            background-color: #ff6900;
            border: none;
            color: #fff;
            font-size: 14px;
        }

        /* 表单禁用伪类选择器 */
        button:disabled {
            opacity: 0.4;
        }
    </style>
</head>

<body>
    <button disabled>注册</button>
    <br>
    <input type="checkbox" id="agree">
    <label for="agree">同意注册协议</label>
</body>

</html>
```



### 伪元素选择器
伪元素选择器，选择元素的特定部分（使用双冒号::）
使用场景：
- 1.让表单里面的placecholder文字变颜色。
- 2.做很多的修饰效果。
作用：
1.选择特定部分：
| 伪元素选择器   | 作用                        |
| -------------- | --------------------------- |
| ::first-line   | 选择首行                    |
| ::first-letter | 首字母                      |
| ::placecholder | 选择input或者textarea占位符 |
<br>
2.插入内容：
| 伪元素选择器 | 作用                               |
| ------------ | ---------------------------------- |
| ::before     | 元素内插入伪元素，作为第一个元素   |
| ::after      | 元素内插入伪元素，作为最后一个元素 |
注意：
- before和after是插入的伪元素，特征类似内联元素。
- content属性是必须，不能省略，没有内容空引号即可。
- 后期非常常用。比如小图标、各种装饰效果。



## 第七章：🎨 CSS属性选择器

使用场景：
- 1.表单样式控制
- 2.图标字体控制
- 3.国际化语言适配等等

## 📚 第八章：CSS三大特性-优先级
- 1.继承性
- 2.重叠性
- 3.优先级
继承性和重叠性前面已提过，这里不再赘述。
优先级原则：
- 1.优先级相等的时候，CSS中最后的那个声明的样式会被应用到元素上。（层叠遵循就近原则）
- 2.其余判断哪个选择器的权重高，优先执行那个样式。
- 3.权重是4位一组，是分开的层级，不能进位。
| 选择器类型          | 示例                    | 权重值    | 优先级说明                  |
| ------------------- | ----------------------- | --------- | --------------------------- |
| !important          | color:red !important    | 无限大    | 强制覆盖所有规则            |
| 内联样式            | <div style="color:red"> | (1,0,0,0) | 行内样式权重最高(1,0,0,0)   |
| ID选择器            | #myid                   | (0,1,0,0) | 每个ID增加0,1,0,0           |
| 类/属性/伪类        | .class，[type="text"]   | (0,0,1,0) | 每个类/属性/伪类增加0,0,1,0 |
| 类型（标签）/伪元素 | div，::before           | (0,0,0,1) | 每个标签增加0,0,0,1         |
| 通配符/继承         | *，继承的样式           | (0,0,0,0) | 通配符和继承性权重最低      |






## 📌 第九章：盒子模型
所有的元素都被一个个的“盒子”包围着，学会盒子模型可以实现精准布局、处理元素排列的关键。
在CSS中，我们有几种类型的盒子，一般区分为块级盒子(block boxes)和行内盒子(inline boxes)
块级盒子(block):
- 1.盒子会产生换行。
- 2.width和height属性可以发挥作用
- 3.不设置宽度，则默认是父元素空间的100%
- 4.内边距、外边距会撑大元素
- 5.常见的比如：div、p、h、ul、table等
行内盒子(inline):
- 1.盒子不会产生换行
- 2.width和height属性将不起作用
- 3.**垂直方向**的内边距、外边距不起效果
- 4.**水平方向**的内边距、外边距会有效果
- 5.常见的比如:span、em、a、strong等
盒子模型的组成：
CSS盒模型整体上适用于区块盒子，包含四部分:
- 1.盒子内容，显示内容的区域，由内容或指定宽度高度来决定内容的大小。
- 2.**内边距padding**，内容距离边框之间的距离。
- 3.**外边距border**，该盒子与其他元素之间的距离。
- 4.**边框margin**，边框盒子包住内容和内边距。

### 盒子模型组成-边框
border属性用于设置盒子边框。
使用场景：
- 1.设置盒子四条或者单独边框。
属性值：
**boder**:边框粗细，边框样式，边框颜色；
- 1.边框由三部分值组成，中间必须空格隔开。
- 2.三部分属性值没有先后顺序。
使用示例：
```CSS
/* 边框  1像素 实线 颜色 */
border: 1px solid #f1f1f1 ;
```
| 边框样式 | 描述     | 视觉效果         |
| -------- | -------- | ---------------- |
| dotted   | 点状边框 | 圆点组成的虚线   |
| dashed   | 虚线边框 | 短横线组成的虚线 |
| solid    | 实线边框 | 单一线条         |

### 盒子模型组成-圆角边框
border-radius允许你设置元素的外边框圆角。
使用场景：
1.盒子设置圆角更好看。
2.盒子或者图片设置为图形。
属性：
bordeer-radius:属性值；
- 数字/百分比
```CSS
.button {
    border-radius: 10px;
}
```
聪明如你，border-radius多个值写法省略。

### 盒子模型组成-内边距
内边距(padding)位于边框和内容区域之间。
使用场景：
- 1.让盒子内容和边框保留一定的距离，更美观。
内边距(padding)多个值用空格隔开，顺时针记忆
单边设置:根据分为名次：left，right，top，bottom

### 盒子模型组成-外边距
外边距(nargin)多个值用空格隔开。
单边设置:根据方位名次:left，right，top，bottom
注意:
- 1.行内元素左右外边距生效，上下外边距无效。
- 2.行内元素设置宽度和高度也无效。

# docs/ — 项目维护文档目录

本目录存放博客项目的**维护性文档**，不参与 Hexo 构建（Hexo 只处理 `source/`，根目录下的 `docs/` 不会被发布到线上）。

## 文档清单

| 文件 | 内容 | 更新时机 |
|---|---|---|
| [01-项目结构分析.md](01-项目结构分析.md) | 全项目扫描：结构、依赖、配置、内容、问题清单 | 结构发生大变化时重新扫描并更新 |
| [02-重构优化方案.md](02-重构优化方案.md) | 分阶段的重构任务清单与验收标准 | 每完成/新增一项任务时勾选更新 |
| [CHANGELOG.md](CHANGELOG.md) | 项目所有变动的历史记录（倒序追加） | 每次产生实际变动后追加一条 |

## 使用约定

- **变动必记录**：任何配置修改、文件增删、文章发布、skill 调整，都要在 `CHANGELOG.md` 追加条目。
- **文档放这里**：今后所有与"项目结构 / 优化 / 变更"相关的 md 文档统一放本目录，不再散落在项目其他位置。
- 文档使用中文撰写，涉及文件路径时写相对路径（相对于项目根目录 `my-blog/`）。

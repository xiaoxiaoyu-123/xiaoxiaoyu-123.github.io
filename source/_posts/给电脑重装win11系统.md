# 💻 给电脑重装win11系统

## 📝 前言
自己在五月份重组了一台电脑，重新安装了 Windows 11。第一次装系统，踩了不少坑：分区报错、强制联网、命令提示符打不了字……折腾了好一会儿才装完。

所以把整个过程整理成这篇**避坑指南**，希望能帮你顺利装完系统，少走弯路。

> **适用场景**：台式机 / 笔记本，安装过程中遇到分区报错、强制联网、键盘无法输入等问题。

## 🚀 一、准备工作
- 一个 **8GB 以上** 的 U 盘
- 下载好的 **Windows 11 官方 ISO 镜像**（建议从[微软官网](https://www.microsoft.com/zh-cn/software-download/windows11)下载）
- 使用 **Rufus**（[下载地址](https://rufus.ie/zh/)）或 **微软官方制作工具** 制作启动盘

## 💿 二、从 U 盘启动
1. 插入 U 盘，开机时连续按 **F12 / Del / Esc**（根据主板品牌不同）进入启动菜单
2. 选择 U 盘（通常带有 **USB** 或 **UEFI** 字样）启动
3. 进入 Windows 11 安装界面，按提示选择语言和版本

> 💡 **提示**：不同品牌的启动菜单按键不一样（也可能是 F2 / F11），拿不准就用搜索引擎/AI 查一下自己电脑品牌对应的按键。

## ⚠️ 三、选择安装位置时可能遇到的问题

### 场景描述
在"选择安装 Windows 11 的位置"界面，可能会看到类似这样的磁盘列表：

| 磁盘 | 类型 | 容量 | 状态 |
| --- | --- | --- | --- |
| 磁盘0 | 机械硬盘 | 931.5GB | 未分配 |
| 磁盘1 | 固态硬盘 | 238.5GB | 已分区 |
| 磁盘2 | U 盘 | 29.7GB | — |

### 常见报错
> 选择此分区进行安装时出错。请选择其他分区或刷新所选内容。

### 解决方法（二选一）

**方法一：删除所有分区，让 Windows 自动重建（推荐）**
1. 选中固态硬盘（磁盘1）下的所有分区，逐个点击"删除(D)"
2. 直到整块磁盘显示为"未分配空间"
3. 选中该未分配空间，直接点击"下一步"
4. Windows 会自动创建所需分区并开始安装

> ⚠️ **警告**：删除分区会**清空该磁盘上的所有数据**！动手前务必确认重要文件已经备份到其他盘或 U 盘。

**方法二：使用 DiskPart 命令手动清空硬盘**
在安装界面按 **Shift + F10** 打开命令提示符，依次输入：

```cmd
diskpart
list disk
select disk 1   ::注意确认磁盘编号，别选错了！
clean
convert gpt
exit
```

完成后点击"刷新"，选中未分配空间继续安装。

## 🌐 四、跳过强制联网（Win11 避坑重点）

### 问题描述
Windows 11 在 **OOBE**（首次开机设置）阶段强制要求连接网络，且部分版本不显示"我没有 Internet 连接"选项。

### 方法一：使用 BYPASSNRO 命令（最常用）
在联网界面按 **Shift + F10**，输入：

```cmd
OOBE\BYPASSNRO
```

系统会自动重启，重启后再次来到联网界面，底部就会出现**"我没有 Internet 连接"**选项。

### 方法二：使用注册表命令（成功率最高）
如果方法一无效，执行以下命令：

```cmd
reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE /v BypassNRO /t REG_DWORD /d 1 /f && shutdown /r /t 0
```

电脑会自动重启，重启后联网界面会出现跳过选项。

## ⌨️ 五、命令提示符无法输入文字怎么办？

### 原因
网络连接页面**抢占了键盘焦点**，导致命令提示符虽然显示在前但未激活。

### 解决方法
1. 用鼠标点击一下命令提示符窗口的标题栏或黑色区域，**激活**它
2. 确认光标（白色下划线）在闪烁后，再尝试输入
3. 如果使用无线键盘，建议更换为 **有线 USB 键盘**，并插在机箱背面接口

> 💡 **提示**：很多"命令打不进去"其实都是没点窗口，鼠标点一下黑窗口就解决了。

## 🗂️ 六、任务管理器中找不到网络相关进程？

### 新旧版本名称对照
| 旧版名称 | 新版名称（Win11 22H2+） | 中文名称 |
| --- | --- | --- |
| OOBE Network Connection Flow | Network Connection Broker | 网络连接流 |
| NetworkConnectionFlow.exe | OOBENetworkConnectionFlow.exe | 网络连接流 |

### 操作步骤
1. 按 **Shift + F10**，输入 `taskmgr` 打开任务管理器
2. 在"进程"或"详细信息"中找到"网络连接流"或 `Network Connection Broker`
3. 右键 → **结束任务**
4. 如果关掉后自动重启，尝试快速连续点击两次"结束任务"，或使用命令：

```cmd
taskkill /f /im OOBENetworkConnectionFlow.exe
```

## 🧰 七、其他可能的跳过命令（备用）
```cmd
start ms-chx:localonly
```

> ⚠️ **注意**：此命令在部分版本中无效，仅作为备用尝试。

## ✅ 八、安装完成后的建议
1. 进入桌面后，连接网络，系统会自动激活（如已绑定数字许可证）
2. 安装**主板 / 显卡**驱动程序
3. 使用磁盘管理对机械硬盘进行**新建分区**，作为数据存储盘
4. 安装常用软件，完成系统配置

## 📋 九、完整问题速查表
| 步骤 | 常见问题 | 解决方案 |
| --- | --- | --- |
| 选择安装位置 | 分区报错 | 删除所有分区，选未分配空间 |
| OOBE 联网 | 无跳过选项 | `OOBE\BYPASSNRO` 或注册表命令 |
| CMD 无法输入 | 窗口未激活 | 鼠标点击窗口内部 |
| 进程关不掉 | 自动重启 | 使用 `taskkill /f` 命令 |

## 🎯 十、总结
重装 Windows 11 并不复杂，关键是在这几个"卡点"上知道正确的操作：

1. **分区报错** → 全删了，让系统自己建
2. **强制联网** → 用 BYPASSNRO 或注册表绕过去
3. **命令输不了** → 点一下黑窗口再输
4. **进程关不掉** → 用 taskkill /f 强杀

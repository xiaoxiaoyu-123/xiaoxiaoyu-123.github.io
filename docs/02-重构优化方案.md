# 重构优化方案

> 依据：2026-10-26 全项目扫描（见 [01-项目结构分析.md](01-项目结构分析.md)）
>
> 原则：**不推翻 Hexo 框架**，先治理地基、再补功能、最后按需升级。每完成一项就勾选 `[x]`，并在 [CHANGELOG.md](CHANGELOG.md) 记录。

## 阶段一：地基治理（P0+P2，低风险，建议最先做）

- [ ] **git init + 首次提交**：把源文件（文章、配置、skill、docs）纳入版本控制；补 `.gitignore`（node_modules、public、.deploy_git、db.json、.claude/poster-work 产物等）
- [ ] **封面图压缩**：`source/img/anime-tech-*.png`（11 张 ×~1.8MB）转 WebP/JPG，目标单张 ≤300KB；同步更新各文章 front-matter 的 cover 路径
- [ ] **补缺失图片**：`favicon.png`、`bg03~bg06.jpg`、`friend_404.gif`、`404.jpg` —— 或制作新图，或改配置移除引用
- [ ] **统一 Live2d 配置**：三处（`_config.yml`、`_config.butterfly.yml`、inject 脚本）收敛为一处，确定模型（miku/koharu）与位置（左/右）
- [ ] **清理冗余**：删除 `source/_posts/test.vue`、`_config.landscape.yml`；移除 `symbols_count_time` 死配置；卸载 8 个未用的 live2d 模型包；决定 landscape 主题依赖去留
- [ ] **生成并部署**：`hexo clean && hexo generate` 确认最新文章进入 `public/`，经确认后 `hexo deploy`（遵守 hexo-deploy skill 的两步确认制）

**验收标准**：仓库有 git 历史；首页单次加载图片总量 < 3MB；全站无 404 图片；线上可见最新文章。

## 阶段二：功能补全（P1）

- [ ] **本地搜索**：安装 `hexo-generator-searchdb`，主题 `search.use: local_search`
- [ ] **评论系统**：推荐 Giscus（基于 GitHub Discussions，零成本）或 Twikoo（需部署后端）
- [ ] **站点统计**：替换/补充 busuanzi（推荐 umami 自托管或 Google Analytics）
- [ ] **修正占位符**：aside "Follow Me" 按钮（现指 `github.com/xxxxxx`）、社交邮箱（`mailto:xxxxxx@gmail.com`）、公告文案、友链数据（`_data/link.yml` 仍是模板默认内容）、音乐页（补内容、修 `descriptiao` 拼写）
- [ ] **分类/标签规范化**：统一命名（去空格、合并近义），修正《Agent开发实习》分类错挂
- [ ] **SEO 细节**：keywords 改英文逗号；评估 permalink 改为 `:year/:month/:title/` 或加装 hexo-abbrlink（注意旧链接 301）

**验收标准**：搜索/评论/统计可用；全站无占位符和默认模板内容。

## 阶段三：视觉与架构升级（可选）

- [ ] **GitHub Actions 自动部署**：push 源文件即自动 build + deploy，替代本地手动 `hexo deploy`（需要管理 deploy key/token）
- [ ] **主题深度定制**：首页布局、暗色模式配色（当前 `background: pink` + light 模式）、字体加载
- [ ] **性能进一步优化**：开启 lazyload、lightbox（fancybox）、preloader 等主题已支持但未启用的能力
- [ ] **封面图体系重建**：底图后端从 SenseNova 换为 Seedream 4.0 垫图生成，完成后全站封面统一重做 → 详见 [03-封面图生成改造方案.md](03-封面图生成改造方案.md)
- [ ] （仅当出现明确痛点才考虑）**框架迁移评估**：Astro / Hugo；文章易迁，但 anime-tech-poster 流水线与 hexo-deploy skill 需重写
